# Project instructions

prism is a Qiskit 2.6 transpiler for encoded (dual-rail) circuits. It carries each gate's realization set across the lowering boundary and binds one realization at routing time. This branch is the tool release and contains only the PRISM method. The HPCA paper's research line, with its baselines, ablations and evaluation pipeline, is on the `hpca-r2` branch (submitted as tag `hpca-r2-submitted`); `hpca-artifact` reproduces the paper.
